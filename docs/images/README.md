# Screenshots

The README expects these four. Names matter; sizes are suggestions.

| File | What to capture |
|---|---|
| `card-back.png` | The back of a good card — a noun with gender, forms and a false friend reads best. ~1040px wide. |
| `terminal.png` | A run of `anki-vocab "el perro"`, from the first INFO line to the last. ~1280px. |
| `card-front.png` | The front: term, sense hint, part of speech. ~640px. |
| `card-back-full.png` | The whole back, scrolled out, next to the front. ~640px. |

Anki's card preview (Browse → select a note → Preview) gives the cleanest shot.
Dark mode screenshots work too — the CSS supports it.
